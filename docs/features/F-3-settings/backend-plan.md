## 4. Настройки: GET и PUT /api/v1/auth/settings

- [x] DTO `UserSettingsResponse` / `UpdateSettingsRequest` — структура из раздела 4.2 системного описания.
- [x] `GET /auth/settings`: возвращает настройки текущего пользователя по `sub` (строка всегда существует — этап 2; при отсутствии — вернуть дефолты и создать строку как fallback).
- [x] `PUT /auth/settings` (полное обновление):
  - валидация: `estimationUnit` ∈ {hours, pomodoros}; `pomodoroMinutes` 5–120 и кратно 5; `budgetHourCost` 1–1000; `gameModeEnabled` — boolean; ошибки — `VALIDATION_ERROR` с `details` по каждому полю;
  - обновление строки `user_settings`, `updated_at = now()`;
  - инвалидация Redis-ключа `settings:{userId}`;
  - ответ — актуальный объект настроек.
- [x] Audit-лог события изменения настроек.

**Готовность:** контракты совпадают с разделами 4.2–4.3 системного описания.
