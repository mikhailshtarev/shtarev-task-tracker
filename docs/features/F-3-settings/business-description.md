# F-3. Персональные настройки и профиль — бизнес-описание

## 1. Обзор

Фича реализует персональный контур пользователя: экран профиля, единицу оценки трудозатрат и настройки игрового режима. Это базовый слой, от которого зависят задачи (F-6), привычки (F-12) и игровой режим (F-13): всё, что вводится и отображается в часах или помидорах, и все начисления наград опираются на настройки из этой фичи.

Источники: [business-requirements.md](../../product/business-requirements.md) (раздел 3 «Персональные настройки», 4.6, 4.9), [non-functional-requirements.md](../../product/non-functional-requirements.md) (раздел 5.2 — персональные данные).

## 2. Профиль пользователя

Пользователь видит экран профиля со своими данными и может изменить отображаемое имя.

| Элемент | Поведение |
| --- | --- |
| Email | Только просмотр; идентификатор аккаунта, изменению не подлежит |
| Имя | Просмотр и редактирование. Для Google-аккаунтов по умолчанию берётся имя из Google; пользователь может его изменить — введённое значение сохраняется и используется везде в интерфейсе |
| Смена пароля | Ссылка на экран смены пароля (реализовано в F-2) |

Требования: имя — необязательное поле (может быть пустым для email-аккаунтов до первого изменения), ограничение длины — до 100 символов. Имя не используется для аутентификации и не влияет на вход.

## 3. Единица оценки

По умолчанию трудозатраты (плановая оценка, фактическое время) измеряются в часах. Пользователь может переключиться на помидоры и указать длительность одного помидора в минутах.

Правила:

1. **Хранение — всегда в часах** с точностью до 5 минут, независимо от выбранной единицы.
2. При единице «помидоры» приложение пересчитывает значения для отображения и округляет до целого помидора. Округление применяется **только к отображению**.
3. Все расчёты — опыт, игровая валюта, личный бюджет (фичи F-13, F-14, F-16) — выполняются по точному значению в часах.
4. Ввод плановой оценки и фактического времени при завершении задачи выполняется в выбранной единице.
5. Смена единицы или длительности помидора влияет на отображение всех существующих задач и привычек — пересчёт исторических данных не требуется, поскольку хранятся часы.
6. Длительность помидора: целое число от 5 до 120 минут, кратное 5; по умолчанию — 25. Это обеспечивает точное хранение значений с шагом 5 минут.

## 4. Игровой режим

Пользователь включает или выключает игровой режим в настройках.

- При **включённом** режиме в интерфейсе отображаются игровые элементы, а за выполнение задач и привычек начисляются опыт и валюта.
- При **выключенном** режиме игровые элементы, прогресс и валюты не отображаются в основном интерфейсе, начисления не производятся, но накопленные данные полностью сохраняются. После повторного включения прогресс и баланс доступны с сохранёнными значениями.
- Состояние по умолчанию для нового пользователя — выключен.
- Доступность игрового режима по тарифам и пробный период — предмет фичи F-15; в рамках F-3 переключатель работает без ограничений по тарифу.

## 5. Настройки наград игрового режима

| Параметр | Назначение | Диапазон | По умолчанию |
| --- | --- | --- | --- |
| Базовый опыт за час (e) | Начисление опыта за задачи: `опыт = x × k × e` | Фиксировано для всех пользователей | 5 (не настраивается) |
| Стоимость часа для личного бюджета (z) | Начисление личного бюджета: `бюджет = x × k × z` | 1–1000 | 5 |
| Базовая награда за час для игровой валюты | Начисление игровой валюты | Фиксировано для всех пользователей | 5 (не настраивается) |
| Коэффициент сложности (k) | Лёгкая / средняя / сложная | Фиксировано | 1 / 1,5 / 2 (не настраивается) |

Где `x` — фактическое время в часах. Пользователь настраивает только `z` бюджета; базовый опыт `e = 5`, базовая награда игровой валюты и коэффициенты сложности фиксированы (решение PM, см. раздел 8).

## 6. Настройки по умолчанию

При регистрации пользователю назначаются:

| Настройка | Значение |
| --- | --- |
| Единица оценки | Часы |
| Длительность помидора | 25 минут |
| Игровой режим | Выключен |
| Стоимость часа для бюджета (z) | 5 |
| Имя | Из Google (для Google-аккаунтов), иначе пусто |

## 7. Критерии приёмки

1. Пользователь видит на экране профиля свой email и имя и может изменить имя; новое имя отображается в интерфейсе.
2. При единице «часы» все трудозатраты вводятся и отображаются в часах с точностью до 5 минут.
3. При переключении на «помидоры» с длительностью 25 минут задача с оценкой 1,5 часа отображается как 4 помидора (округление 3,6 → 4), а расчёт наград использует точные 1,5 часа.
4. Смена единицы не меняет сохранённые данные: после переключения туда и обратно значения отображаются исходно.
5. Выключение игрового режима скрывает игровые элементы; включение возвращает их с сохранённым прогрессом и балансом.
6. Ввод значений вне допустимых диапазонов (длительность помидора, z) отклоняется с понятным сообщением.
7. Настройки сохраняются на сервере и применяются после входа с любого устройства.

## 8. Решения и допущения

| # | Решение | Обоснование |
| --- | --- | --- |
| 1 | Базовая награда игровой валюты фиксирована (5) для всех пользователей, настраивается только z личного бюджета | Согласовано: валюта должна начисляться единообразно, индивидуальная калибровка — только у бюджета |
| 2 | Имя профиля редактируемо и перекрывает имя из Google | Решение PM от 2026-09-12 |
| 3 | Диапазоны: помидор 5–120 мин с шагом 5, z 1–1000; базовый опыт e фиксирован на 5 | Консервативные ограничения для валидации; в БТ диапазоны не заданы |

| 4 | Базовый опыт за час e фиксирован на 5 и не является пользовательской настройкой | Единый темп прогрессии для всех пользователей | Значение задаётся игровой логикой, в Settings отсутствует |

Решение о фиксированных базовых значениях опыта и игровой валюты синхронизировано с БТ 4.9.

## 9. Вне рамок фичи

- Само начисление опыта, валюты и бюджета — F-13, F-14, F-16.
- Ограничения игрового режима по тарифам и пробный период — F-15.
- Изменение пароля и вход через Google — F-2.
- Дополнительные настройки округления отображения помидоров — задел на будущее.
